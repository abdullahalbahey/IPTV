Live TV Guide

What's airing right now, fetched live from broadcast schedules. Search a show or network, or browse by country.

Schedule data from TVMaze, fetched live in your browser. The country list is built from whatever TVMaze actually returns data for - not a guessed list - so it only offers countries with real coverage. That coverage is still TVMaze's own crowdsourced database, skewed toward US/UK/AU-style broadcast markets; it doesn't cover the 1,270 IPTV playlists indexed on the main page, and TVMaze's own listings can run late or be wrong.

Live TV Guide is a separate feature from the playlist index above - it does not use iptv-org data. If TVMaze is unreachable or rate-limits this page, the guide below will show an error instead of silently guessing.
