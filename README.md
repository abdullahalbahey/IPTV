# IPTV

A browsable, searchable index of every playlist published by [iptv-org/iptv](https://github.com/iptv-org/iptv). Click any row to copy its `.m3u` link, then paste it into VLC, Kodi, or any player that opens a network stream.

Live page: https://abdullahalbahey.github.io/IPTV/

Reference from: https://github.com/iptv-org/iptv
